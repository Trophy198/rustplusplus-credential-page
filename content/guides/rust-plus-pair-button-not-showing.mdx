Rust+ is not a feature of your game client. It is a feature the **server** exposes, and every server owner decides whether to turn it on. When the ESC menu has no Rust+ entry, or the entry is there but the **Pair with server** button is not, the server has Rust+ disabled or misconfigured. There is no phone setting, reinstall or account fix that changes this.

## Confirm it in 30 seconds

1. Stay connected to the server in question. Press **ESC**. If there is no **Rust+** item in the menu at all, the server has the companion app disabled. Stop here; go to "What the admin has to do".
2. If the **Rust+** item exists, click it. You should see a **Pair with server** button. If the panel shows text but no button, or a message about Rust+ being unavailable, same conclusion.
3. To prove it is the server and not you, join any **official Facepunch server** and repeat. Official servers always show the button. If you see it there and not on the community server, you have your answer.

## Why servers turn it off

Some admins disable Rust+ on purpose: it lets players see team positions and control smart devices remotely, which certain hardcore and roleplay servers consider unfair. Others turn it off unintentionally, by running a server behind a host that does not forward the companion port, by setting `app.port -1` in an old config, or by restoring a config from a server that had it disabled. Modded servers occasionally lose it after a plugin update changes convars.

## What the admin has to do

The server needs three things, all on the server side. If you know the admin, send them this list.

1. **Enable the companion port.** The convar is `app.port`. It defaults to the game port plus 67 (28082 on a stock 28015 game-port setup). A value of `-1` disables Rust+ entirely. `app.info` in the server console prints the current port and whether the companion server is listening.
2. **Make that TCP port reachable from the internet.** Forward it on the router or open it in the host's firewall, exactly like the game port. The phone app connects to it directly. Some panels expose this as a "Rust+" or "Companion port" toggle; others require a support ticket.
3. **Let the server reach `companion-rust.facepunch.com`.** Outbound access is needed to register the server and send pairing notifications. A locked-down host firewall can block it.

After changing the port the server must restart. Then ESC → Rust+ should show the button.

## The one case where it is your side

If the button **appears on some servers and not others for you, while your friend sees it on the same server**, you may be looking at a stale menu: the Rust+ panel is populated when you join. Disconnect, reconnect, and open ESC again. If it still differs between you and a teammate on the same server at the same time, report it as a client bug; the panel should be identical for everyone connected.

## Not the same as "Pair does nothing"

If the button **is** there but pressing it produces nothing on your phone, the server has Rust+ on and the fault is elsewhere. Continue with [Rust+ won't pair or gets stuck](/guides/rust-plus-not-pairing).

## For rustplusplus users

The same rule applies to the bot: it cannot pair with a server that has Rust+ disabled, because no pairing notification is ever sent. If your bot lists some servers but never a particular one, check that server's ESC menu before touching the bot or your [credentials](/docs/credentials-web-version).
