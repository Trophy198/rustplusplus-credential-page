This site does one job well: it gives you the Rust+ credentials the **rustplusplus** Discord bot needs, in one click, without downloading an executable. Around it we keep the bot's documentation current and, over time, add guides and tools for people who run Rust+ and rustplusplus.

## What rustplusplus is

[rustplusplus](https://github.com/alexemanuelol/rustplusplus) is a free, open-source Discord bot by **alexemanuelol**, licensed under the GPL-3.0. It connects to the Rust+ companion API so your team can see server status, chat, control smart switches, receive alarms and track players from Discord. Each team hosts its own instance; there is no central service.

## What this site is

- **The credential extension and this web app** are maintained by [Trophy198](https://github.com/Trophy198), the author of the browser extension the official rustplusplus documentation refers to for the web credential flow. Source code: [rustplusplus-credential-page](https://github.com/Trophy198/rustplusplus-credential-page) and [rustplusplus-credentials-extension](https://github.com/Trophy198/rustplusplus-credentials-extension).
- **The documentation pages** under `/docs` are mirrored from the upstream repository's `docs/` folder and synced automatically. Each page states which upstream file and commit it came from. Corrections belong upstream; they flow here.
- **Guides and tools** published here are written for this site and are our own work.
